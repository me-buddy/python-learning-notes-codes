=============================== Constraints in MySQL ========================================
=> These are the restrictions which apply on particular column.

SYNTAX:- columnName dataType CONSTRAINTs

1. NOT NULL :- It is used to make a column Not Empty
.......................................................................................
2. UNIQUE :- it ensures that every column Name should be unique.
.......................................................................................
3. AUTO_INCREMENT :- It automatically assign value to that column.
NOTE :- This column must be Primary Key
.......................................................................................
4. CHECK condition :- It is used to apply custom condition on any column.
ex:- marks int CHECK marks>0
.......................................................................................
5. DEFAULT value :- used to provide a default value to any column, it assign a default value if user does not pass any value
ex:- city varchar(100) DEFAULT "Mathura"
.......................................................................................
6. PRIMARY KEY :- It apply two constraints on a column it make sure that particular column should be "unique" and can not be "Empty(NOT NULL)" 
NOTE :- Every table can have Only ONE Primary Key.
.......................................................................................
7. FOREIGN KEY :- it is used to create a link between two tables.
NOTE :- It create a link on "Primary Key" Column of another table. 
This mechanism enforces "referential integrity"

syntax:-
---------
create table table1Name(
    id int Primary key AUTO_INCREMENT,
    name varchar(200),
    age tinyint
);

create table table2Name(
    Roll_Number int Primary key AUTO_INCREMENT,
    id int NOT NULL UNIQUE,
    Section varchar(20),
    Address varchar(200)

    FOREIGN KEY id REFRENCES table1Name(id)
);


==================================================== operators in mysql =================================================
Operators are some special symbols used to perform some specific task/operation.

1. Arithematic operators :-
-----------------------------
+ (addition)
- (substraction)
* (multiplication)
/ (division)
% (Modulas) => Used to find Remainder
ex:- 15%2 => 1
ex :- 30%4 => 2

2. Relational/Comparision operators :- It is used to "compare two values" return true(1) or false(0).
--------------------------------------
> (greater than)
< (lessthan)
>= (greater than OR equal to)
<= (lessthan  OR equal to)
<> OR != (Not equal To)   <>
= (IsEqual To )

ex:- 18>7 => true
ex:- 18<7 => false
ex:- 18<>7 => true OR 18!=7 => True
ex:- 10 = 10 => true
ex:- 10>=6 => true
ex:- 10>=10 => true

3. Logical operators :- These operators are used to "compare two Conditions" return true(1) or false(0).
-----------------------
=> AND (logical and) :- return true if both conditions are true , return false if either one condition is false.
syntax:- (condition1)AND(condition2)

ex:- (10>5)AND(10>20) ===> false
ex:- (10<5)AND(10<20) ===> false
ex:- (10>5)AND(10<20) ===> true

=> OR (logical or) :- return true if either one condition is true , return false if both conditions are false.
syntax:- (condition1) OR (condition2)

ex:- (10<5)OR(10<20) ===> true
ex:- (10>5)OR(10>20) ===> true
ex:- (10>5)OR(10<20) ===> true
ex:- (10<5)OR(10>20) ===> false

=> NOT (logical not) :- it reverse the condition, true ---> false , false ----> true
syntax:- NOT(condition)

ex:- NOT(10>5)===> false
ex:- NOT(10<5)===> true

4. Between :- It is used to retrieve(get/fetch) data in a range(starting and ending values)
syntax :- select columnName1 , columnName2 ,.. FROM tableName WHERE columnName BETWEEN startValue AND endValue ;
ex:- SELECT * FROM bank_transactions WHERE transaction_id BETWEEN 10 AND 30;

5. LIKE :- Used to filter/search records according to given pattern with LIKE operators.
Here we use Two symbols(wildcard characters) with like operator:-
-------------------------------------------
% :- used to fetch zero or more characters.
_ :- used to fetch single character only.

Syntax:- SELECT * FROM tableName WHERE columnName LIKE "pattern";
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
NOTE :- It does not follow ASCII Code.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
EX:-
----
SELECT * FROM employees WHERE name LIKE "R__"; ==> return those employees records where name starts with R and followed by two characters.
SELECT * FROM employees WHERE name LIKE "R%"; ==> return those employees records where name starts with R and followed by more than one characters.
SELECT * FROM employees WHERE name LIKE "%n"; ==> return those employees records where name ends with n .
SELECT * FROM employees WHERE name LIKE "A%n"; ==> return those employees records where name starts with A and ends with n.

6. IN , NOT IN :- The IN operator filters your query to return only rows where a column's value matches any item in the provided list

ex:- SELECT * FROM employees WHERE city IN ("Delhi","Mumbai","Chennai"); -- select all records where city belongs to Delhi , Mumbai and Chennai
SELECT * FROM employees WHERE city NOT IN ("Delhi","Mumbai","Chennai"); -- select all records except city belongs to Delhi , Mumbai and Chennai

===================================================== GROUP IN MySQL ============================================================
=> it is used to group multiple columns in a table with Aggregated functions(COUNT , SUM , AVG , MIN , MAX).

NOTE :- If any column used with select command is Non-Aggregated(varchar or date) should also include with GROUP BY.

SELECT columnNames , AggregatedFunction(columnName)
FROM tableName
WHERE condition
GROUP BY columnName 
HAVING condition;


example :-
----------
SELECT category, SUM(quantity) AS total_units, SUM(total_amount) AS total_revenue,max(total_amount)
FROM sales_data
GROUP BY category;

OR

SELECT store_location,category,sum(quantity) AS "Total Items" ,SUM(total_amount) AS "Total Revenue",max(total_amount)
from sales_data
GROUP BY store_location,category
HAVING sum(quantity)>3;
